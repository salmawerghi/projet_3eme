Toutes les maquettes de DarImmo, prêtes pour Figma

Chaque écran reprend les vrais champs de la base Supabase : statuts d'annonce, motif de rejet, conversations liées à une annonce, jetons de notification. Les écrans du membre C sont en premier.

Les couleurs s'inspirent de Sidi Bou Saïd : bleu des portes, ocre des façades, fond sable. Le bouton « Sombre » montre la version mode sombre (story 2.6).

Importer dans Figma (plugin fourni)

  1. Ouvrez l'application Figma Desktop. Un plugin local ne s'importe pas depuis le navigateur.
  2. Créez un fichier de design, puis menu Plugins → Development → Import plugin from manifest… et choisissez : D:\flutter\flutter_application_1\projet_3eme\design\figma-plugin\manifest.json
  3. Lancez Plugins → Development → DarImmo Maquettes. En 20 secondes environ, une page « DarImmo · Maquettes v3 » apparaît.
  4. Tout est modifiable : auto-layout, textes, et couleurs reliées aux variables (modes Clair et Sombre).
